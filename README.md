# 🏗️ Richter Construções — Sistema de Orçamentos Profissionais

Aplicação web moderna, intuitiva e completa para criação, gerenciamento e geração de orçamentos em PDF com a identidade visual oficial da **Richter Construções**.

## 🌟 Funcionalidades

- **💾 Banco de Dados de Orçamentos**:
  - Salva, edita, duplica e exclui orçamentos diretamente no navegador.
  - Controle de status: *🟡 Rascunho*, *🔵 Enviado*, *🟢 Aprovado*, *🔴 Recusado*.
  - Histórico pesquisável por nome do cliente, endereço ou número da proposta.
  - Exportação e importação de backups completos em formato `.json`.
- **📄 Suporte Multi-páginas Automático**:
  - Capacidade de 10 itens por folha no modelo oficial.
  - Ao ultrapassar 10 itens, novas páginas são criadas automaticamente sem quebrar o cabeçalho nem o layout original.
  - Botão de expansão rápida de página (+10 itens).
- **🧮 Cálculo Financeiro em Tempo Real**:
  - Soma automática dos itens (Quantidade × Preço Unitário).
  - Campo opcional de desconto.
  - Opção de total automático ou valor total manual.
- **⚡ Atalhos Rápidos**:
  - Sugestões de serviços frequentes com 1 clique (Pintura, Assentamento de Piso, Elétrica, Hidráulica, etc.).
  - Cláusulas e termos prontos para observações (validade, garantia, formas de pagamento, descarte de entulho).
- **📱 Compartilhamento via WhatsApp**:
  - Envio direto de mensagem personalizada com o resumo da proposta para o WhatsApp do cliente.
- **🌐 100% Client-Side & Offline Ready**:
  - Funciona perfeitamente hospedado no **GitHub Pages** ou localmente com duplo clique (`file:///`).
  - Sem necessidade de servidor backend nem banco de dados externo.
